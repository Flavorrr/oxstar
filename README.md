Oxstar Consultancy Website

This repository contains the source code for the official website of Oxstar Consultancy Limited, a premier research and development firm based in Nairobi, Kenya, with operational reach across the Horn of Africa.

 Overview

Established in 2012, Oxstar Consultancy provides evidence-based research, monitoring & evaluation, and capacity development services. The website serves as a digital storefront, showcasing the company's services, team, partners, and project portfolio.

Key sections of the site include:

· Home: Introduction and company overview.
· About: Vision, mission, and background.
· Services: Detailed descriptions of their consulting offerings.
· Team: Profiles of the leadership and staff.
· Contact: Ways to get in touch.

 Features

· Modern, Responsive Design: Built with a clean, professional aesthetic that adapts to different screen sizes.
· Dynamic Color Palette: Uses a comprehensive CSS variable system for primary, secondary, and accent colors, allowing for easy theming and consistency.
· Service Showcase: Clearly presents the firm's five core service areas: Research & M&E, Training & Capacity Development, Disaster Risk Management, Livelihood & Climate Change, and Policy & Strategic Planning.
· Partner Logos: Displays logos of collaborating organizations, including the UN, UNDP, UNICEF, and Welthungerhilfe.
· Project Imagery: Includes a folder (oxstar Consultancy/) with images from various field projects and training sessions.

 Setup & Installation

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/Flavorrr/oxstar.git
   ```
2. Navigate to the project directory:
   ```bash
   cd oxstar
   ```
3. Open the website:
   · Simply open index.html in your web browser.
   · For a better development experience, you can use a local server (e.g., with VS Code's Live Server extension).
